# Developer protection

The developer/company-managed profile explicitly protects shell configuration,
Oh My Zsh, Git, SSH, AWS, Azure, GCP, Kubernetes, Terraform, Docker, VS Code,
Homebrew, package-manager state, local AI tooling, `~/Library`, repositories, and
common project markers. Kubeconfigs use bounded structural detection without
logging contents or secrets. Company security and repository archives require
manual review.
